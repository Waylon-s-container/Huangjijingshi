# 皇极经世

一个以邵雍《皇极经世》时间哲学为内容的单页 Web 应用：**时钟日历 + 学术教材**二合一。

纯静态、零依赖、零构建。所有计算在浏览器端完成。

---

## 这是什么

本站有两部分，通过 hash 路由切换：

### 1. 封面——皇极经世时钟日历

以「元会运世」（邵雍创设的四级时间单位）呈现当前时刻在宇宙时间结构中的位置。

- **六十四卦水墨圆图**（Canvas 水墨写意笔触）
- **当前年值年卦**朱砂描边 + 墨晕呼吸高亮
- **时间轴漫游**：拖动可查任意年份的元会运世定位与值年卦
- **三栏布局**：卦象圆图 / 竖排卦辞 / 元会运世数值表

### 2. 教材——皇极经世学术研究级读本

以原典原文为骨架、引述历代注疏、配以图解与交互演示的学术教材。

| 章 | 标题 | 对应原著 |
|----|------|---------|
| 导言 | 皇极经世是什么 | — |
| 第一章 | 元会运世的数理结构 | 卷一-二 数理 |
| 第二章 | 先天六十四卦图 | 卦图体系 |
| 第三章 | 卦气配法 | 配卦法 |
| 第四章 | 以元经会·以会经运（数表推演） | 卷一-四 第1-23篇 |

## 学术处理

本项目遵循三条学术红线：

1. **原典为骨架**——原文引述标明出处（篇名/卷次），电子本查证自 [ctext.org](https://ctext.org/wiki.pl?if=gb&res=809496&remap=gb) 与 [维基文库](https://zh.wikisource.org/zh-hans/皇极经世)
2. **引述注疏**——历代各家观点（祝泌、张行成、蔡元定、朱熹、王植、邵伯温等）以引述形式呈现，每条标明注者与书名
3. **不原创学术论断**——导读与要点只做事实性串联；有争议处并列诸说不下结论（如配卦法的变爻方向分歧、旬卦合法性等）

每节正文遵循**五段式结构**：【导读】+【原典】+【注疏】+【图解】+【要点】。

## 核心算法

所有时间计算在 `js/data/calendar.js`，纯函数，可单元测试。

| 项 | 值 |
|----|-----|
| 一元之初 | 公元前 67017 年（据邵雍所标历史事件反推） |
| 人事纪年起 | 帝尧元年（公元前 2357 年，甲辰） |
| 换算关系 | 1元 = 12会 = 360运 = 4320世 = 129600年 |
| 无公元0年 | 已校正（前 A 年到后 B 年 = A + B − 1） |
| 卦序 | 先天六十四卦圆图（邵雍「加一倍法」= 严格二进制序），坤起顺时针至乾 |
| 值年卦配法 | 去四正卦（乾坤坎离），余六十卦配六十甲子；以 2026=同人 为基准外推 |

**黄金回归用例**（多源文献交叉确认）：2026 年 = 午七会 · 全元第 192 运 · 第 10 世 · 世中第 13 年。

> 注：值年卦采「基准外推法」，与正宗「世卦起年」配法不同（后者依赖世卦确定，存在变爻方向分歧，见教材§3.3）。本站未实作完整推演链。

## 视觉风格

古籍水墨风，全站统一：

- **宣纸米黄底** `#f4ecd8` + 径向纹理
- **思源宋体**（Noto Serif SC）
- **卦象主图**：毛笔写意（墨色浓淡、枯笔飞白）
- **卦象详情**：工笔规整（等宽墨线）
- **当前锚点**：朱砂描边 `#a02020` + 墨晕呼吸动效
- **印章**：朱砂篆书方印

支持**简繁切换**（基于 [OpenCC](https://github.com/nk2028/opencc-js)，内容源为繁体，即时转换为简体显示；含术语保护，如「乾」卦名不被误转为「干」）。

## 技术栈

- **原生 HTML / CSS / JavaScript（ES Modules）**——零构建、零框架、零依赖
- **Canvas 2D** 用于水墨卦象与圆图
- **SVG** 用于锚点、印章、图解
- **hash 路由**（`#/book/ch1`）实现封面↔教材的单页切换
- **发布-订阅 + 单一 state**（`js/store.js`）驱动多模块联动
- **OpenCC**（CDN）简繁转换
- 测试用 Node 内置 `node:test`（无需安装依赖）

## 本地运行

需通过本地静态服务器访问（ES Modules 在 `file://` 协议下会被 CORS 拦截）：

```bash
# 任选一种
npx serve .
# 或
python -m http.server 8765
# 或用本项目自带的
node spike/server.mjs . 8765
```

浏览器打开 `http://localhost:8765/`。

运行测试：

```bash
npm test
# 或
node --test
```
