# 皇極經世

一個以邵雍《皇極經世》時間哲學為內容的單頁 Web 應用：**時鐘日曆 + 學術教材**二合一。

純靜態、零依賴、零構建。所有計算在瀏覽器端完成。

---

## 這是什麼

本站有兩部分，通過 hash 路由切換：

### 1. 封面——皇極經世時鐘日曆

以「元會運世」（邵雍創設的四級時間單位）呈現當前時刻在宇宙時間結構中的位置。

- **六十四卦水墨圓圖**（Canvas 水墨寫意筆觸）
- **當前年值年卦**朱砂描邊 + 墨暈呼吸高亮
- **時間軸漫遊**：拖動可查任意年份的元會運世定位與值年卦
- **三欄佈局**：卦象圓圖 / 豎排卦辭 / 元會運世數值表

### 2. 教材——皇極經世學術研究級讀本

以原典原文為骨架、引述歷代注疏、配以圖解與交互演示的學術教材。

## 學術處理

本項目遵循三條學術紅線：

1. **原典為骨架**——原文引述標明出處（篇名/卷次），電子本查證自 [ctext.org](https://ctext.org/wiki.pl?if=gb&res=809496&remap=gb) 與 [維基文庫](https://zh.wikisource.org/zh-hans/皇极经世)
2. **引述注疏**——歷代各家觀點（祝泌、張行成、蔡元定、朱熹、王植、邵伯溫等）以引述形式呈現，每條標明注者與書名
3. **不原創學術論斷**——導讀與要點只做事實性串聯；有爭議處並列諸說不下結論（如配卦法的變爻方向分歧、旬卦合法性等）

每節正文遵循**五段式結構**：【導讀】+【原典】+【注疏】+【圖解】+【要點】。

## 核心算法

所有時間計算在 `js/data/calendar.js`，純函數，可單元測試。

| 項 | 值 |
|----|-----|
| 一元之初 | 公元前 67017 年（據邵雍所標歷史事件反推） |
| 人事紀年起 | 帝堯元年（公元前 2357 年，甲辰） |
| 換算關係 | 1元 = 12會 = 360運 = 4320世 = 129600年 |
| 無公元0年 | 已校正（前 A 年到後 B 年 = A + B − 1） |
| 卦序 | 先天六十四卦圓圖（邵雍「加一倍法」= 嚴格二進制序），坤起順時針至乾 |
| 值年卦配法 | 去四正卦（乾坤坎離），餘六十卦配六十甲子；以 2026=同人 為基準外推 |

**黃金回歸用例**（多源文獻交叉確認）：2026 年 = 午七會 · 全元第 192 運 · 第 10 世 · 世中第 13 年。

> 註：值年卦採「基準外推法」，與正宗「世卦起年」配法不同（後者依賴世卦確定，存在變爻方向分歧，見教材§3.3）。本站未實作完整推演鏈。

## 視覺風格

古籍水墨風，全站統一：

- **宣紙米黃底** `#f4ecd8` + 徑向紋理
- **思源宋體**（Noto Serif SC）
- **卦象主圖**：毛筆寫意（墨色濃淡、枯筆飛白）
- **卦象詳情**：工筆規整（等寬墨線）
- **當前錨點**：朱砂描邊 `#a02020` + 墨暈呼吸動效
- **印章**：朱砂篆書方印

支持**簡繁切換**（基於 [OpenCC](https://github.com/nk2028/opencc-js)，內容源為繁體，即時轉換為簡體顯示；含術語保護，如「乾」卦名不被誤轉為「干」）。

## 技術棧

- **原生 HTML / CSS / JavaScript（ES Modules）**——零構建、零框架、零依賴
- **Canvas 2D** 用於水墨卦象與圓圖
- **SVG** 用於錨點、印章、圖解
- **hash 路由**（`#/book/ch1`）實現封面↔教材的單頁切換
- **發布-訂閱 + 單一 state**（`js/store.js`）驅動多模塊聯動
- **OpenCC**（CDN）簡繁轉換
- 測試用 Node 內置 `node:test`（無需安裝依賴）

## 本地運行

需通過本地靜態服務器訪問（ES Modules 在 `file://` 協議下會被 CORS 攔截）：

```bash
# 任選一種
npx serve .
# 或
python -m http.server 8765
# 或用本項目自帶的
node spike/server.mjs . 8765
```

瀏覽器打開 `http://localhost:8765/`。

運行測試：

```bash
npm test
# 或
node --test
```
