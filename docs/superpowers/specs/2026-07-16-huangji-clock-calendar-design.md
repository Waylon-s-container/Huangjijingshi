# 皇极经世书时钟日历 · 设计文档

> 创建日期：2026-07-16
> 状态：已确认，待转入实现计划

## 一、定位

**可视化探索皇极经世时间哲学体系的单页 Web 应用。**

以卦象为导向，三层尺度（会/运宏观 → 值年中观 → 日卦微观）层层下钻，让人直观漫游邵雍元会运世的宏大时间结构。无后端、无数据库，所有计算在浏览器端完成。

核心理念：人的一生在元会运世的尺度下只是一个点。本应用让用户能"站在卦象里"感受时间的纵深，而非做一个干巴巴的换算工具。

## 二、三层尺度与交付计划

采用**分三层递进**的交付策略。每层交付时都是可独立使用的产物，最后串联成完整体验。

| 阶段 | 层 | 主视觉 | 时间轴尺度 | 交付目标 |
|------|-----|--------|-----------|---------|
| **P1** | 中观 · 值年卦 | 64卦圆图，当前年朱砂+墨晕高亮 | 年级（漫游任意年份） | 核心体验跑通 |
| **P2** | 宏观 · 会/运 | 十二消息卦嵌套圈 | 万年级 | 宏观结构可见 |
| **P3** | 微观 · 日卦 | 日卦月历 | 日级 | 日常可用 |
| **串联** | 三层联动 | 尺度切换器激活，下钻/上卷 | 时间轴随尺度变化 | 完整体验 |

**导航逻辑**：宏观 ↕ 中观 ↕ 微观，层层下钻/上卷。用户可在任意尺度停留、漫游，也可点击下钻进入更细的尺度，或上卷回到更大的尺度。

## 四、核心算法（追求学术准确）

### 4.1 起算点

- **采用**：尧元年（公元前 2357 年），通行说
- 依据：《皇极经世·观物篇》，以尧即位为元之始推算的落点
- 学术上存在其他取法（如公元前 2577 年等），本项目采用通行说并透明声明

### 4.2 元会运世换算

纯算术换算，有唯一正确解：

```
1元 = 12会 = 129600年
1会 = 30运 = 10800年
1运 = 12世 = 360年
1世 = 30年
```

核心函数：
```
gregorianToHuangji(year) → { yuan, hui, yun, shi, yearInShi }
  1. year - (-2357) = 距尧元年年数（注意无公元0年）
  2. / 129600 → 元；余 / 10800 → 会；余 / 360 → 运世
```

### 4.3 卦象配法

皇极经世的卦象配法存在多家之说（康节原文、朱熹后学、近人张其成等整理）。本项目策略：

- **选定一套自洽方案**作为默认，明确标注出处
- **模块化实现**，后续可切换不同流派的配卦法
- **不伪装配法为唯一正解**

各层配法（具体采用哪套流派方案，在各阶段实现时查文献选定并在代码与页脚标注；此处先确定配法框架）：

| 层 | 配法框架 | 实现时选定 |
|----|---------|-----------|
| 值年卦（P1） | 六十四卦圆图序轮流值年 | 查文献选定具体圆图序与基准年，标注出处 |
| 会/运消息卦（P2） | 十二消息卦对应十二会（子复→午姤…） | 查文献选定消息卦与会对应关系，标注出处 |
| 日卦（P3） | 基于值年卦 + 月日推演 | 查文献选定日卦推演法，标注出处 |

### 4.4 透明声明

页脚永久显示：
```
起算：尧元年（前2357）· 配卦法：[方案名·出处]
```

## 五、视觉风格（古籍水墨风）

### 5.1 色彩与质感

| 要素 | 规格 |
|------|------|
| 背景 | 宣纸米黄 `#f4ecd8` + SVG 噪点纹理 + 边缘做旧渐变 |
| 主图卦象 | **毛笔写意**——墨色浓淡变化、枯笔飞白（模拟真实毛笔） |
| 详情卦象 | **工笔规整**——等宽墨线，清晰可辨（像古籍刻本） |
| 当前锚点 | **朱砂描边 `#a02020` + 墨晕呼吸动效** |
| 印章 | 朱砂篆书方印，角落半透明 |
| 标题/卦名 | 墨黑 `#2a2418`，思源宋体 Bold |
| 正文/解析 | 墨黑 `#2a2418`，思源宋体 Regular |
| 数字（年份） | 等宽衬线，避免跳动感 |

### 5.2 字体

- 思源宋体（Noto Serif SC），本地打包或 CDN 引入
- 标题/卦名 Bold，正文 Regular

### 5.3 当前锚点交互（朱砂 + 墨晕）

- **朱砂描边**：定位"这里就是现在"，朱红圆圈描边当前卦象
- **墨晕呼吸**：表现"时间在流动"，墨色从中心向外晕开的呼吸动画
- 拖动时间轴时，朱砂游标移动，圆图高亮跳到对应卦象，墨晕重新晕开

## 六、交互

| 操作 | 行为 |
|------|------|
| 拖动时间轴 | 朱砂游标移动 → 主图高亮跳到对应时刻 → 墨晕重晕 |
| 点击主图卦象 | 弹出详情面板（工笔卦象 + 卦名 + 卦辞/消息 + 简析 + 对应时间范围） |
| 悬停卦象 | 显示卦名 tooltip |
| 尺度切换器（串联后） | 在宏观/中观/微观三层间切换，时间轴随之变化尺度 |
| 下钻/上卷（串联后） | 点击当前层元素进入更细尺度，或返回上层 |

## 七、技术架构

```
皇极经世书时钟日历/
├─ index.html
├─ css/style.css
├─ js/
│   ├─ data/
│   │   ├─ hexagrams.js      64卦 + 十二消息卦数据（名/辞/爻/阴阳）
│   │   ├─ calendar.js       公历↔皇极历换算核心
│   │   └─ eras.js           元会运世结构 + 当前定位
│   ├─ render/
│   │   ├─ InkBrush.js       水墨写意笔触绘制器（共享）
│   │   ├─ HexagramMap.js    P1 值年卦圆图（Canvas）
│   │   ├─ EraRings.js       P2 会/运嵌套圈（Canvas）
│   │   ├─ DayGrid.js        P3 日卦月历（Canvas/SVG）
│   │   ├─ Anchor.js         朱砂+墨晕锚点（SVG）
│   │   └─ DetailPanel.js    详情面板（工笔卦象）
│   ├─ TimeScrubber.js       时间轴（随尺度变化）
│   ├─ ScaleSwitcher.js      尺度切换器（P1灰显→串联激活）
│   └─ app.js                入口、状态管理、事件绑定
└─ assets/                   宣纸纹理、印章SVG、字体
```

- 原生 HTML/CSS/JS，零构建步骤，双击 `index.html` 即可运行
- Canvas 用于圆图、水墨写意、嵌套圈等需绘制渲染的部分
- SVG 用于锚点、印章、tooltip 等矢量元素
- 部署：纯静态，可托管于任意静态服务器或 GitHub Pages

## 八、不做（YAGNI）

- ❌ 用户账号 / 云端存储
- ❌ 多语言（MVP 仅中文）
- ❌ 占卜 / 命理功能（只做时间结构可视化与解析）
- ❌ 伪装配卦法为唯一正解（始终标注出处、可切换）
- ❌ P1 阶段激活尺度切换器（灰显预留，串联阶段激活）

- **P1 交付**：打开页面可见宣纸底 + 64卦水墨圆图，当前年（2026）朱砂+墨晕高亮，拖动时间轴可漫游任意年份并切换值年卦，点击卦象弹出工笔详情面板
