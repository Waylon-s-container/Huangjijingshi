## 一、定位

**一本 web 端的皇极经世书学术研究级教材**，以原典原文为骨架、引述历代注疏（标明出处）、配以图解与可交互演示。

现有三栏时钟日历（P1 已完成）作为**首页封面**，提供"当前时刻在元会运世中的位置"这个直观入口，点击进入多章节教材。

### 内容来源策略（学术可靠性的命脉）

- **原典为骨架**：以 ctext.org / 维基文库的原文为骨架，原文引述必须标明出处（如《皇极经世·观物篇》卷次）
- **引述注疏**：历代各家观点（朱熹后学、张行成《皇极经世索隐》、王植、祝泌《观物篇解》、近人整理）以引述形式呈现，每条标明注者与出处
- **不原创学术论断**：导读与要点只做事实性串联，不做学术判断。有争议处并列各家观点
- **诚实标注**：我（AI）的知识有盲区，正文涉及的具体年份、卦象配法、注疏归属等必须可查证；不确定处明确标注"待考"，不臆断

## 二、站点架构

```
皇極經世 (单页应用，hash 前端路由)
│
├─ #/ (首页/封面)
│   └─ 三栏时钟日历（P1已完成）+ 新增「入讀教材」入口按钮
│
├─ #/book (教材)
│   ├─ 左侧：章节目录（持久导航，可折叠）
│   ├─ 右侧：当前章节正文
│   └─ 顶部：返回封面 + 章节进度
│
└─ #/book/intro, #/book/ch1, #/book/ch2 … (各章节)
```

**技术：** 纯静态单页，hash 路由（`#/book/ch1`），零依赖、零构建。教材内容以 JS 数据模块组织（每章一个文件），便于逐章追加。复用已有的宣纸水墨视觉风格与 Canvas/SVG 渲染能力。

## 四、教材正文呈现形式（每节五段式）

每节按统一结构组织，保证学术可查证性：

```
§X.Y 小节标题
├─ 【導讀】     简短导读（讲清楚这节要解决什么问题，事实性陈述）
├─ 【原典】     原文引述（灰色框，标明出处：篇名/卷次）
├─ 【注疏】     历代各家观点引述（每条标明注者+书名+出处）
│              · 朱熹后学：…
│              · 张行成《皇极经世索隐》：…
│              · 祝泌《观物篇解》：…
├─ 【圖解】     交互式图示（复用 Canvas/SVG，如元会运世嵌套圈、方圆图）
└─ 【要點】     本节要点小结（事实性，非论断）
```

**五段式原则：**
- 原典与注疏是"引述"（可查证），用视觉样式与正文区分
- 导读与要点只做事实性串联（"邵雍将一元分为十二会"），不做学术判断（不说"邵雍正确地指出"）
- 有学术争议处，并列各家观点，标注分歧，不下结论
- 原文引述必须可追溯到 ctext/维基文库的具体篇卷

## 五、视觉风格（延续古籍水墨风）

复用时钟日历已建立的视觉语言，保持站点统一：

| 要素 | 规格 | 复用情况 |
|------|------|---------|
| 背景 | 宣纸米黄 `#f4ecd8` + 纹理 | 复用 |
| 字体 | 思源宋体（Noto Serif SC） | 复用 |
| 正文 | 宋体 Regular，墨黑 `#2a2418`，适合长文阅读的行距(1.9)与字号(16px) | 新增（教材正文优化） |
| 原典框 | 浅灰底 `#ebe0c8`，宋体，缩进，左侧朱砂细竖线标示 | 新增 |
| 注疏条目 | 小字(13px)，每条前缀注者名（朱砂色），缩进分级 | 新增 |
| 章节标题 | 宋体 Bold，字号层级（章24px/节18px/小节15px） | 新增 |
| 图解 | 复用水墨 inkBrush 与 Canvas 能力 | 复用 |
| 导航 | 左侧目录竖排或横排，当前章节高亮（朱砂） | 新增 |

**路由实现（零依赖 hash 路由）：**
```javascript
// router.js
const routes = {
  '#/': renderCover,           // 时钟日历封面
  '#/book': renderBookIndex,   // 教材目录（默认跳导言）
  '#/book/intro': renderChapter,
  '#/book/ch1': renderChapter,
  '#/book/ch2': renderChapter,
};
window.addEventListener('hashchange', () => routes[location.hash]?.());
```

封面与教材共用同一 index.html，通过 hash 切换挂载的视图，避免多 HTML 文件。

## 七、教材内容数据结构

每章为一个 JS 模块，导出结构化内容，便于渲染与维护：

```javascript
// book/ch1-yuanhuiyunshi.js
export default {
  id: 'ch1',
  title: '元會運世的數理結構',
  sections: [
    {
      id: '1.1',
      title: '元會運世的定義',
      intro: '导读文本...',           // 【導讀】
      source: {                        // 【原典】
        text: '《皇極經世》一元，十二會...',
        citation: '《皇極經世·觀物篇》',
      },
      commentaries: [                  // 【注疏】
        { author: '邵雍', work: '皇極經世', text: '...' },
        { author: '张行成', work: '皇极经世索隐', text: '...' },
      ],
      diagram: 'eraNesting',           // 【圖解】组件名
      summary: '要点文本...',          // 【要點】
    },
    // ...更多小节
  ],
};
```

## 十、验证标准

- **封面→教材：** 时钟日历页面有「入讀教材」按钮，点击 hash 跳转 `#/book/intro`
- **教材框架：** 左侧目录列出导言+第一章+第二章（后续章节灰显），点击切换正文
- **正文五段式：** 每节完整呈现导读/原典（带出处框）/注疏（带注者标示）/图解/要点
- **图解交互：** 第一章元会运世嵌套圈可看，第二章方圆图可看
- **学术规范：** 每条原典引述可追溯到篇卷，每条注疏标明注者与书名，无原创论断
- **视觉统一：** 教材页与封面同为古籍水墨风，阅读体验连贯
